# 开发规范

## 技术约定

Node.js 22+，原生 ES Modules，UTF-8、LF、两个空格缩进。运行时无第三方依赖，不需要打包器即可启动。前端修改后刷新页面；`npm run dev` 只提供 Node watch，不是热模块替换。

在库函数与网络边界写清输入、输出和失败方式。函数尽量承担单一职责，使用显式名称，避免宽泛 catch 后静默继续。能够成为纯函数的计算逻辑放到 `web/lib/`，用 Node 内置测试验证。浏览器模块不导入服务器模块；服务器可以复用环境无关的合同和算法。

## 目录责任

| 位置 | 允许承担的责任 | 避免放入 |
| --- | --- | --- |
| `web/content/` | 课文、代码展示、题目、来源与目录数据 | 网络调用、存储副作用 |
| `web/lib/` | 可独立测试的算法、协议、状态和数据合同 | DOM、隐式全局 UI 状态 |
| `web/ui.js` | 共享转义、图标、简单展示辅助 | 供应商凭证或网络规则 |
| `web/app.js` | 路由、课程模板、记录、导航 | 直接构造各供应商请求 |
| `web/labs.js` / `trace-lab.js` | 实验 DOM、用户控制、清理 | 隐藏付费调用、无上限循环 |
| `web/playground.js` | 用户配置、预览、显式发送与取消 | 持久化密钥、跨域直接发密钥 |
| `server/` | 本机 HTTP、目标约束、预算、HTTPS 传输 | 课程排版和浏览器状态 |
| `tests/` | 可复现断言与浏览器验收 | 有效密钥、默认外部付费调用 |

## 数据与状态

课程 ID、实验 ID 和 Hash 路由是稳定公共标识。存储使用 `harness-lab:v1` 及明确版本和字段白名单；改格式必须写迁移或可解释的重置策略。不要把配置对象整体塞入存储，因为以后可能新增秘密字段。

模型文本、用户输入和历史内容通过 `escapeHTML` 或 `textContent` 渲染。只有项目维护的模板可以进入 `innerHTML`。JSON 先解析，再检查合同；解析成功不等于业务合法。

`mountLab` 与真实体验挂载函数返回清理函数。路由切换前先执行清理，停止计时器、取消请求并释放页面中的凭证。自动演示必须由用户点击开始；停止、重置、完成、失败、审批等待都需要明确行为。

## 页面视觉

样式令牌集中在 `styles.css` 的 `:root`。沿用现有层级、卡片、表单、空态和提示组件；先复用，再抽象，不为一次性展示建立复杂框架。使用系统字体和自有 SVG，不默认增加外部素材请求。动画帮助解释状态，不替代实际状态机。

至少检查 1440 px 桌面与 390 px 手机宽度。长模型名、长 JSON、中文说明、错误消息和空列表都不能撑破布局。输入有 label，图标按钮有可访问名称，键盘可达，状态有文字，减少动画偏好得到尊重。

## 测试与交付

提交前运行 `npm run verify`。修改界面再运行 `python tests/browser_smoke.py`；浏览器依赖安装方式见 [TESTING.md](TESTING.md)。重要修复必须包含回归案例。不得通过删断言或吞掉异常来“修复”测试。

PR 说明区分单元测试、服务集成、浏览器 mock 和真实供应商验证。没有凭证时可以完成前几层，但不能声称已经真实联调。变更页面入口或课程目录时同步 [PAGES.md](PAGES.md)；变更限制时同步 [API.md](API.md) 和 [SECURITY.md](../SECURITY.md)。

## 添加减法工具的例子

先在计算器测试加入 `subtract` 的正数、负数、零和非法输入案例；随后扩展 `calculator.js` 中的允许操作与实现，再更新 `protocol.js` 的共享 Schema、参数实验、相关课文和协议测试。所有入口应共享相同合同，不在各供应商适配器中复制一份不同的验证规则。

新增第三方包、真实网络调用、存储字段、工具能力或权限放宽都需要在 PR 中明确提出理由、许可、替代方案与测试影响。尤其不能为“兼容性”直接去掉来源、私网或重定向限制。
