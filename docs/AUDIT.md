## 具体问题与修复

1. **CI 中断**：permissions 自测反馈恰为 10 个字符，违反已有 `>10` 的内容检查。补充解释并在报错中输出课程 ID，未降低阈值。基线三个核心 CI 均失败；浏览器任务通过。
2. **历史链路不完整**：已有持久化与展示，没有导入、检索或继续入口。增加独立 history 模块，任务标签按白名单保留；旧格式不误当作可发送上下文。
3. **文档引用缺文件**：README/开发规范引用不存在的 TESTING.md，并声称提供未提交的 Pages/模板。补齐实际文件，加入本地 Markdown 链接检查。
4. **MCP 描述未固定版本**：核对当前 2026-07-28 文档，更新发现/元数据示例，标明旧版生命周期差异。本站仍不冒充真实 MCP Client。
5. **学习密度与可观察步骤**：原概念段落加逐行代码仍缺具体输入-输出对照；增加全课 worked examples，并通过浏览器验收验证切换、边界按钮和预测题展开。
6. **返回缓存生命周期**：路由挂载组件退出会清理；浏览器从 back-forward cache 恢复时重新挂载，避免保留已 disposed 的 API 页面。
