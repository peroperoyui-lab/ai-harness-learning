# 架构与数据通路

## 两条运行路径

免密钥路径：`app.js` 路由 → 课程/实验挂载 → `web/lib` 纯函数 → 可观察结果。课程快照不执行代码；状态机模型输出为脚本，计算器、装箱、TF-IDF、SSE、成本和测试断言是真实本地运算。

真实 API 路径：`playground.js` 明确读取表单 → `protocol.js` 构造预览 → 用户授权 → POST `/api/demo` → `server/index.mjs` 重复检查来源、预算、凭证、目标 → `security.mjs` 公网解析/白名单 → `upstream.mjs` 一次有界 HTTPS 调用 → 协议归一 → 可选一次本地计算器执行 → 页面显示。没有自动第二次请求、自动重试或模型列表探测。

公开静态构建只复制 `web/` 到 `dist/`。真实中继只绑定本机；浏览器检查 `/api/config` 及来源后才开放真实模式。这是个人教学服务，不是多租户网关。

## 依赖方向

`content` 只输出数据；`lib` 不使用 DOM；`ui` 提供安全显示辅助；各页面挂载 DOM 并返回 cleanup；`app` 管理路由和共享 store。server 复用环境无关合同，不让浏览器引用服务器文件。节点和消息按明确状态推进；终态不再执行动作。

## 历史与续聊

`storage.js` 对 localStorage version 1 做字段白名单、20 会话/40 消息限制，失败退回内存并提示。`history.js` 检查导入格式、容量和 ID 冲突，并决定哪一组消息可发往模型。`history-page.js` 只负责查询和用户操作。

续聊先恢复文字；连接、密钥、费用授权、携带历史和保存开关不恢复。用户重新配置并勾选后，最多携带一组明确标注 explain 的问答，每条 400 字符。更改接收服务/模型/协议时重新确认。未知任务的旧记录和工具轨迹只读，不作为自动指令。

## 扩展检查清单

新增工具：共享合同 → 参数/权限/拒绝测试 → 实现 → 实验 → 课程与目录。新增协议：请求与响应夹具 → serializer/normalizer → 服务预算检查 → 表单预设 → mock UI → 可选一次真实联调。新增页面：课程数据或挂载模块 → 路由入口 → cleanup → 键盘/移动端 → 文档与浏览器测试。
