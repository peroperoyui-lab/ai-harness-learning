# Harness Lab · AI Harness 交互学堂

**看见 AI 如何工作，亲手搭起它的运行系统。**

面向初学者的中文交互学习站。通过 **24 节课程、11 类本地实验、41 条术语解释**，把模型请求、工具调用、上下文、记忆、工作流、权限和测试连成一条完整的工程通路。

不需要 API Key 就能学习全部课程、运行全部实验。可选的真实 API 工作台采用小输出预算、单次手动请求和受限本机中继；学习进度与主动保存的会话留在当前浏览器。

## 立即运行

需要 **Node.js 22 或更新版本**与现代浏览器。项目没有第三方运行时依赖，**无需 npm install**。

```bash
git clone https://github.com/peroperoyui-lab/ai-harness-learning.git
cd ai-harness-learning
npm start
```

打开终端提示的 `http://127.0.0.1:4173`。按 **Ctrl+C** 停止服务，关闭浏览器页面并不会自动关闭 Node 进程。

Windows 用户也可以通过 GitHub 的 **Code → Download ZIP** 下载并解压，在项目文件夹打开终端后运行 `npm start`。不要直接双击 `web/index.html`：浏览器的 ES Module 安全机制要求通过 HTTP 服务加载。

端口被占用时：

```bash
npm start -- --port=4174
```

首次建议：**学习总览 → 第 1 课 → Agent 循环观测台 → 参数验证 → API 体验中的免密钥模式**。页面中的参考学习时长只是阅读与练习估计，可按自己的节奏推进。

## 你能在这里做什么

### 24 节课程，六个阶段

| 阶段 | 四节课程 |
| --- | --- |
| 建立工程直觉 | Harness 与 Agent、最小 JavaScript、消息与 Token、协议适配器 |
| 让 Agent 动起来 | 循环状态机、工具合同、流式解析、失败与重试 |
| 管理信息与记忆 | 上下文选择、RAG 与检索、记忆与检查点、Skill 渐进装载 |
| 组织协作与交付 | 工作流、多 Agent、MCP、结构化输出与成果 |
| 守住安全与预算 | 人工审批、提示注入、隔离与凭证、Token 预算 |
| 测试并交付项目 | 运行轨迹、评估与回归、部署与开发、完整通路实作 |

每节课包含学习目标、三段概念讲解、三个可手动切换的预设实例快照、预测题与迁移说明、逐行注释代码、实现文件链接、常见错误、动手任务、自测题和原始参考资料。**伪代码、项目真实函数片段和概念图式会分别标明。**

### 11 类可操作实验

| 实验 | 实际交互 |
| --- | --- |
| Agent 循环观测台 | 逐步执行、自动播放、回看快照、停止、审批、保存轨迹；正常、参数错误、人工批准和循环上限四种场景 |
| 工具参数工作台 | 编辑 JSON，区分语法与合同错误，真实执行受限加法／乘法 |
| 上下文装箱 | 修改容量和输出预留，选择候选内容，观察保留、舍弃与溢出 |
| 迷你检索 | 对内置文档执行 TF-IDF 余弦检索，查看匹配词、得分与来源 |
| 协议 X 光机 | 比较四种协议预设中的消息、输出限制和工具 Schema |
| 流式字节实验 | 将 UTF-8 中文 SSE 切成任意小块，逐块递送并观察完整事件 |
| 工作流调度 | 调整任务时长，比较串行／并行的完成时间与总工作量 |
| 检查点实验 | 推进任务、持久保存、清空临时状态、刷新后恢复 |
| 信任边界 | 比较可疑文本提示与独立执行权限，观察拒绝和模拟批准 |
| Token 预算 | 修改输入、缓存、输出、假设单价与调用次数，实时计算 |
| 回归测试台 | 用五个固定案例对比正确实现与“全部做加法”的错误基线 |

### 可选的真实 API 体验

在本机页面打开 **API 体验 → 真实 API**，选择服务与协议，填写准确的模型名称和自己的密钥，检查请求预览后发送。

支持以下请求预设，不承诺所有兼容服务接受全部字段：

| 预设 | 端点 | 输出限制字段 |
| --- | --- | --- |
| OpenAI Chat · modern | `/chat/completions` | `max_completion_tokens` |
| Chat Completions · compatible | `/chat/completions` | `max_tokens` |
| OpenAI Responses | `/responses` | `max_output_tokens` |
| Anthropic Messages | `/messages` | `max_tokens` |

真实任务有简短解释、JSON 提示约束与一次计算器工具调用。JSON 模式会检验语法与字段，但不是供应商强制结构化输出。工具模式只执行一个获准、通过验证的本地计算器调用，**不会自动进行第二次模型请求**。

**费用控制：**默认输出上限 128，最高 256；本次输入最多 600 字符；默认不带历史，可明确选择携带上一组问答，每条最多 400 字符。服务端重复校验这些约束，每分钟最多 12 次尝试，同时只运行一个请求，20 秒超时，不自动重试、不探测模型列表。输出上限不是总费用保证，实际费用受模型、输入、推理和服务计价影响；小预算也可能导致空或截断回答。用量缺失显示“未知”。

**凭证处理：**密钥只用于当前页面和单次中继请求，不写入 localStorage、日志、仓库或导出。刷新、离开体验页、切回免密钥模式或点击清除后需要重新填写。请使用低额度、可撤销的学习凭证；浏览器扩展、本机恶意软件和供应商的数据策略不在本项目控制范围内。

自定义可信 HTTPS 服务需要显式允许主机名：

```bash
npm start -- --allow-host=your-provider.example
```

地址只允许 HTTPS 默认端口、公网 IPv4 解析结果和明确允许的主机，不跟随重定向。暂不支持本地 Ollama、私网模型端点、任意请求头或代理配置。详见 [API 说明](docs/API.md)。

## 会话与学习记录

课程进度保存在浏览器。运行轨迹通过“保存轨迹”保存；API 问答只有勾选“保存到当前浏览器”才持久化。最多保留最近 **20 个会话，每个 40 条消息**，可以查看、导出、单独删除，或清除全部学习数据。

数据仅在当前来源与浏览器内有效，不跨设备同步，也不是加密存储。隐私模式、配额或浏览器策略导致存储不可用时，会提示并退回内存。改变 localhost、127.0.0.1 或端口会形成不同的浏览器存储来源。

## 工程结构

```text
web/
  index.html, styles.css, learning.css   页面入口与原创视觉
  favicon.svg                           原创站点图标
  app.js, ui.js                        路由、阅读、导航、记录与安全渲染
  labs.js, trace-lab.js                 11 类交互实验
  playground.js                        免密钥／真实 API 体验
  content/                             六组课程、24 个分步实例、目录、术语与来源
  lesson-guide.js / history-page.js     分步阅读与可恢复的本地记录
  lib/                                 可独立测试的状态机、算法、协议与存储
server/
  index.mjs                            本机静态服务与 API 边界
  security.mjs                         目标校验、公网地址与来源规则
  upstream.mjs                         有界 HTTPS 请求、响应归一与工具执行
scripts/                               检查与静态构建
tests/                                单元、合同、集成与浏览器测试
docs/                                 页面目录、架构、开发、API 和验证说明
.github/                               CI、Pages 发布与贡献模板
```

运行时零外部包，使用原生 JavaScript ES Modules 与 Node 内置模块。框架升级、供应商 SDK 和大量依赖不会成为初学者读懂核心代码的前置条件。

## 历史会话与继续学习

学习记录支持标题/内容搜索、单会话和全部 JSON 导出、验证后导入及继续问答。恢复会话不会发送模型请求、恢复密钥或继承费用授权；真实连接须重新填写。只有明确勾选后，最近一组标注为简短解释的问答才会进入下一次请求，每条最多 400 字符。旧记录、工具和 JSON 输出保留查看，但不隐式发送。导入最多 2 MiB，同 ID 创建副本，超过总容量会先提示。

## 开发与测试

```bash
npm run dev       # Node watch 模式；前端修改后手动刷新浏览器
npm run check     # JavaScript 语法、课程结构、引用键与实现文件检查
npm test          # 无供应商外网调用、无真实密钥的单元和本机集成测试
npm run build     # 仅将课程前端生成到 dist/
npm run verify    # check + test + build
```

浏览器测试使用可选的 Python Playwright，见 [测试说明](docs/TESTING.md)。测试中的模型服务是明确注入的假实现，**不等于已经通过真实供应商的付费接口联调**。

## 静态发布

`dist/` 可部署在 GitHub Pages 等静态托管平台，Hash 路由兼容仓库子路径。公开静态站提供完整课程、所有本地实验和免密钥体验；真实 API 模式保持禁用，需要在本机运行中继。

仓库提供 Pages 工作流。首次需要仓库管理员在 **Settings → Pages → Source** 选择 **GitHub Actions**，再手动运行 Pages 工作流。仅提交工作流文件不代表站点已经发布成功。

## 当前边界与扩展方向

本项目是一份可运行、可拆解的教学实现。模型循环使用确定性脚本，检索实验使用词面 TF-IDF，时间和上下文容量为教学数据。MCP、多 Agent、Skill、生产级沙箱和外部成果存储有课程说明，但没有伪装成已经实现的完整基础设施。真实体验目前使用非流式单次响应，SSE 解析在独立本地实验中学习。

欢迎通过小而可验证的 PR 增加课程或实验。建议首次贡献从增加减法工具、补充协议边界测试、改进移动端可访问性或校正课程引用开始。更复杂的运行设施先开设计 Issue，保持免密钥路径可靠、默认费用低、密钥不持久化。
